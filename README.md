# HCI Master Quiz App (Weeks 1 – 12)

An interactive, responsive single-page web quiz application for Human-Computer Interaction (HCI) covering all 120 questions across Weeks 1 to 12.

## ✨ Features
- **120 Verified Questions**: Direct from course assignments with accurate answers.
- **Practice Mode**: Instant feedback on selection with answer explanation.
- **Exam Mode**: Test conditions with submission and score analysis.
- **Search & Navigation**: Jump palette and keyword search.
- **100% Offline Capable**: Zero external dependencies required.
